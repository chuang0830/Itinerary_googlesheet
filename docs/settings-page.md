# 網站設定頁（Phase 7 的 Settings 範圍）

從 ☰ → Settings · 網站設定進入，可查看旅行名稱、副標題、開始／結束日期及主題色。具 Google 編輯權限及 app 檔案授權者可點 Edit。

編輯中所有變更都是本機草稿。四種主題色（森林綠、海洋藍、莓果紫、暖陶棕）即時預覽於設定頁，不會自動儲存。既有自訂 HEX 主題色可保留。Done 驗證後寫入 Settings，Cancel 放棄並還原預覽。日期使用 YYYY-MM-DD 純文字。縮短日期範圍不刪除任何行程／住宿／交通，範圍外資料留在 Sheets。

後端使用目前使用者自己的 OAuth Token，驗證同源、登入及原生 canEdit，寫入前核對 Settings 內容摘要，寫後重新讀取確認。失敗保留草稿，衝突／撤權鎖住編輯並提供複製與放棄後重新載入。Google Sheets 的直接編輯競態限制與 Phase 5 相同。

只更新 tripName / subtitle / startDate / endDate / themeColor 對應的五個 B 欄 Value 格，保持原列位置、Key、格式及未認識的設定鍵，不更名 Spreadsheet，也不修改其他工作表。公式會阻止編輯，避免無意覆寫。原始 Settings 格式不正確時須先在 Sheets 修正。

## 驗證

69 項自動測試與正式建置通過。新增測試涵蓋五值更新、未認識設定與列順序保留、日期／色碼驗證、純文字寫入、衝突、撤權、重試及寫後確認。瀏覽器讀取真實設定成功，375px 預覽無水平溢出。實際測試海洋藍與旅行名稱的草稿預覽，公開 API 確認原 Settings 未變；Cancel 還原森林綠及原名稱。未登入及跨站 PUT 分別回 401 / 403。

真實 Done 改動設定、另一個 Google 帳號撤權與手機實機仍待驗證。此項工作僅完成設定頁，未追加完整分享整合或部署。
