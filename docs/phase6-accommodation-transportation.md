# Phase 6 — 住宿與交通管理

## 功能與操作

每日行程、住宿及交通頁左上角新增 ☰ 選單。選單包含每日行程、Accommodation、Transportation 及開啟 Google Sheets。Settings 與完整分享功能留待 Phase 7。

住宿及交通頁可公開檢視，具 Google 原生編輯權限與 app 檔案授權者可點 Edit。新增、修改、刪除只更新本機草稿；按 Done 才批次儲存，Cancel 放棄。日期一律以 YYYY-MM-DD 的 stringValue 純文字寫入，時間使用 HH:mm，不將單引號存進內容。

Accommodation 支援飯店名稱、城市、入住／退房日期與地圖連結；可新增多筆，入住含當晚、退房不含當晚。Transportation 支援 Flight / Train / Bus / Other、出發／目的地、日期時間、業者、班次及訂票連結。每筆住宿／交通都只存在各自工作表，不複製到 Itinerary。

儲存後返回每日行程會重新讀取四表，資訊卡依日期顯示住宿與多筆／跨日交通，訂票及地圖連結可開啟。編輯中選單停用，避免不小心切頁丟失草稿；其他會離開頁面的普通連結會觸發瀏覽器未儲存提示。

## 安全與同步

兩個管理 API 都驗證同源 Origin、Session、Google 授權及原生 canEdit；使用目前使用者自己的 OAuth Token。寫入前重新讀取並核對該工作表的內容摘要，衝突拒絕，不覆蓋其他工作表。每個工作表只更新受管理欄位的 userEnteredValue，保留格式並清除舊尾列，必要時同批次擴列。

輸入驗證包含日期真實性及區間、必填欄位、交通類型、連結與大小。空白新記錄不寫入；真實公式阻止編輯以避免靜默改成文字。寫入後重新讀取確認，一致才顯示 Synced；前次成功但回應遺失時，重試會確認已有相同結果，不重複寫入。

暫時錯誤保留草稿供重試；401 / 403 / 409 鎖住編輯，提供複製草稿及明確的放棄後重新載入操作。仍有 Phase 5 已說明的 Google Sheets 直接編輯競態限制，本機鎖無法保證完全零遺失更新。另一個 Google 編輯者帳號仍待實際權限測試。

## 驗證

61 項自動測試通過，含前階段與：住宿 CRUD、多筆交通、原生日期時間轉換、YYYY-MM-DD 字串寫入、日期／連結驗證、空白列、衝突、撤權、尾列清除、重試與寫後確認，以及每日資訊卡的退房與跨日交通判斷。

瀏覽器已驗證真實交通資料可讀取並進入表單，新增／修改／刪除草稿未改變 Google Sheets，Cancel 還原原交通；未登入的住宿及交通 PUT 都回 401。住宿頁也已確認可讀取現有兩筆住宿及帶入 ISO 日期至編輯表單，375px 手機預覽沒有水平溢出；Cancel 正常返回。真實 Done 改動資料與雙帳號撤權、手機實機觸控仍待驗證，不將模擬 Google 測試當成端對端寫入測試。
