# 旅行介面語言

建立表單可選繁體中文或 English；選擇後，表單與預覽立即切換。
建立時將 `language` 作為 Key / Value 存入同份 Spreadsheet 的 Settings：

| Key      | Value       |
| -------- | ----------- |
| language | zh-TW 或 en |

沒有此設定的舊旅行預設顯示繁體中文。未知的語言值會被拒絕，避免靜默使用錯誤設定。

旅行頁、日期列、行程編輯、住宿、交通、分享與設定頁共用該旅行的語言，旅行彼此不共享語言狀態。
旅行名稱、副標題、活動、飯店、城市與連結保留原文；不進行內容翻譯。
四個工作表名稱、表頭、交通 Type 與 YYYY-MM-DD 日期儲存格式維持原本資料規格。

設定頁可修改語言，遵循 Done 儲存／Cancel 放棄。舊試算表首次修改語言時會補上 language 列，保留既有設定、額外 Key 與列位置。

驗證涵蓋建立與讀取、舊資料相容性、非法語言拒絕、設定寫入、每趟旅行的語言及中英文頁面輸出。
真實 Google 登入與建立試算表仍需使用者登入後驗收；測試不代為授權或建立公開旅行。

## 翻譯檔案與代號

元件使用固定英文代號，例如 `t('tripName')`。
文字分別放在 `lib/trip/locales/zh-TW.ts` 與 `lib/trip/locales/en.ts`，
以 `TranslationKey` 保證代號存在，兩個語言檔的代號保持一致。
修改顯示文字只需調整語言檔，不必更改元件代號。

既有 API 回傳的錯誤與狀態文字經由 `localizeMessage` 相容處理，與元件的 `t()` 分開。
使用者填寫的旅行名稱、行程與住宿等資料不傳入翻譯函式。
