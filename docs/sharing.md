# 分享整合

主行程頁的 Share 開啟分享視窗。依使用者要求，選單不顯示分享入口。

- 顯示旅行主網址 origin/{spreadsheetId}，不把 accommodation / transportation / settings 子路徑、query 或 hash 放進分享連結。
- 複製旅行網址成功後才顯示成功；若 Clipboard API 無法使用，網址仍可選取手動複製。
- 支援 Web Share 的瀏覽器顯示「開啟系統分享」。使用者取消不顯示失敗，其他錯誤提示改用複製。
- 原生 dialog 支援鍵盤 Escape、焦點限制與關閉後還原焦點，手機版適配。
- 分享不修改 Sheets 權限、不新增編輯者，也不讀寫旅行資料。編輯模式中仍停用選單，以保護未儲存草稿。
- 本機 localhost / loopback 網址會提示朋友無法從自己的裝置開啟；正式部署後使用部署網站的 origin。

正式建置通過。瀏覽器已驗證選單入口、旅行網址、複製成功提示、設定子頁分享回旅行主網址，以及 375px 手機分享視窗；未替使用者在系統分享選單選擇收件者或傳送訊息。
